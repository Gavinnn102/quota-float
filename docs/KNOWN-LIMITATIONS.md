# 已知限制

- Codex 数据来自非公开只读接口，字段、认证方式或访问策略可能变化。
- 点数余额读取现有 `/backend-api/wham/usage` 的 `credits.balance`；该字段返回原始点数而非美元金额，独立于重置机会。美元展示目前使用个人 Credits 的每点 US$0.04 换算口径（25 点 = US$1），并保留两位小数。这是美元换算值，不是折扣购入成本或钱包余额，不能作为企业合同结算金额。
- 美元显示使用固定换算比例，不请求官方动态定价或美元估算接口，不随购买地区、折扣或合同自动调整。若点数面额变化，需要同步更新 `src/lib/format.ts` 中的换算常量。
- 缺失或无效点数余额显示 `—`，明确的零余额显示 `US$0.00`，无限点数账户显示“不限量”/“Unlimited”。短时刷新失败时沿用已有过期状态及 30 分钟缓存规则；退出登录或缓存超过 30 分钟后隐藏余额。
- Windows 与 macOS 保留原有原生发布；Linux 当前只正式支持 Ubuntu 26.04 x86_64、GNOME Wayland 会话和 `.deb`，不提供 AppImage 或 RPM，其他桌面环境或 X11 不保证精确锚定。
- Ubuntu 的 ChatGPT 窗口锚定依赖随包 GNOME Shell 扩展，当前支持 GNOME Shell 48–50。被系统策略禁用时无法进行跨应用精确定位。
- Ubuntu 的 100 × 100 紧凑圆球会根据宿主边框几何及全屏/最大化状态预留位置：宿主既非全屏也非完全最大化时保持 GNOME 桌面坐标中的右侧 24 px，并从默认底边锚点上移 136 个逻辑 px；有效几何缩放为 1 的常规逻辑桌面上对应底边 160 px，其他缩放/坐标模式由组件自身的窗口几何换算。全屏或完全最大化时恢复默认 24 px；320 × 320 完整面板始终使用默认右下 24 px。半屏平铺和单轴最大化仍使用紧凑模式的避让位置，宿主过矮时会钳制到顶部；该逻辑不读取输入区内容或进行像素识别。
- 宿主拖动和调整大小的平滑跟随依赖 GNOME 的窗口位置/尺寸/状态事件；250 毫秒检查只负责发现和恢复。事件合并、宿主切换、缩放和跨显示器行为仍需在目标桌面实机确认。
- GNOME Shell 通常只在登录会话启动时扫描新安装的系统扩展；首次安装、更新或移除后可能需要注销并重新登录。
- Ubuntu 扩展只在 ChatGPT 为活动应用（或用户正在操作组件）时显示组件；应用会在正常退出时尝试禁用扩展，但崩溃、强制结束或系统策略可能阻止清理。
- GNOME 是否显示 AppIndicator 取决于桌面会话；无法显示时仍可从活动概览启动应用。
- XDG autostart 依赖桌面环境遵守 `~/.config/autostart`；部分窗口管理器可能需要用户自行配置。
- CSS 毛玻璃效果取决于平台 WebView、显卡驱动和合成器，像素表现可能不同。
- Claude provider 在 v1 中未启用。
- 重置机会仅展示数量和到期时间，不能在应用内兑换。
- 真实额度准确性依赖 Codex 后端返回的窗口数据；应用不会根据本地 Token 消耗自行估算。
